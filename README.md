# Lotto Number Picker

A free web app that picks UK Lotto, Thunderball, EuroMillions and Set For Life numbers from the most-drawn numbers.

- Live app: https://airich49.github.io/lotto-picker/
- Short link to share: https://bit.ly/LuckyBallPicker
- Support the app: https://ko-fi.com/luckyballpicker
- Install it on a phone: open the link, then **Add to Home Screen** (iPhone, Safari Share menu) or **Install app** (Android, Chrome menu).
- Draw history lives in `data/*.csv` and is updated nightly by a scheduled task.

Every ball has the same chance in every draw, so following the stats doesn't change your odds. 18+ only.
